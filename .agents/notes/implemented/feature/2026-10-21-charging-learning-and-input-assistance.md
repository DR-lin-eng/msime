# Agent Note: 充电夜间学习与本机输入辅助

Status: implemented

## Problem

个人排序头只在当前选词和冷启动时有限重放，不能利用充电空闲时段集中优化。剪贴板采集已经存在，但普通验证码消息会进入长期历史；短信验证码没有原生接收、短时提示和点击填入链路。

## Decision

共享 Rust 层提供夜间 00:00–06:00、充电且空闲、学习开启且非无痕的门禁，并对最多 512 个已有个人词对做八轮重放。数值头保存到原有 SQLite 学习日志中的独立表，以现有词对散列绑定；后续学习、删除和清理后不能复用旧模型。平台负责系统任务调度和取消，输入会话占用时不训练。

验证码识别、剪贴板历史排除放在 client-core，宿主只在授权后观察短信或剪贴板。验证码只在内存保留五分钟；点击才插入，插入不经过选词学习和输入统计，不保留短信正文。剪贴板读取和记录继续受既有历史开关、敏感标记和隐私模式约束；键盘显示和实时偏好首次打开历史时补读当前内容，以已有身份去重，避免冷启动时复制事件先到而漏记。

## Existing decisions

[自适应神经排序](../../implemented/feature/2026-10-21-adaptive-neural-prediction.md)部分重叠，扩充离线训练时机和缓存；[剪贴板开启引导](../../implemented/feature/2026-10-17-android-clipboard-voice-onboarding.md)部分重叠，保留开关和清空语义，不另建第二份历史。没有完全吸收或过时提案。

## Alternatives considered

- 持续在击键路径训练更大的模型能及时响应偏好，但会占用键盘线程、电量和内存；额外训练安排在充电夜间空闲任务。
- 把全部剪贴板和短信送入语言模型能得到更多语料，但会把他人的文字和临时凭据当成用户选词偏好；本次只训练既有选词日志，验证码仅作短期填入提示。
- 默认申请读取所有历史短信实现更容易，但实际需要的只是新到验证码；使用可撤销的系统接收权限，不申请历史短信读取。

## Consequences

额外训练不进入击键线程；数值头可跨进程和重启复用，仍以日志散列防止删除或新学习后的旧缓存残留。夜间任务默认开启，服从原有学习与无痕开关。短信提示默认关闭，打开后请求可撤销的 `RECEIVE_SMS`；不申请 `READ_SMS`，只处理新到短信。识别出的单个数字码在内存中保留五分钟，点击才直接插入当前输入连接，不经过学习、上下文缓存和统计。剪贴板历史开关保持原默认值，开启后才捕获，原有敏感标记、隐私模式和输入框限制继续生效。

代价是 SQLite 学习日志多一张数值缓存表，Android 多一个受充电、空闲约束的系统任务和一个授权后可工作的短信接收器。移动系统可能延后任务，不能保证固定时刻运行；每个本地日期最多成功训练一次。Apple 平台的短信数据库不属于第三方键盘可读接口，本轮原生调度和短信界面只接入 Android。共享层的验证码识别与历史排除可由其他宿主复用。

## Verification

Docker 同输入探针：原版没有夜间和验证码动作，普通文本与带验证码语义的消息都会进入历史；修改版对不充电和白天返回 `skipped`，充电夜间返回 `trained`，普通文本保留、验证码不入历史且可识别。共享层回归覆盖夜间条件、缓存持久化及日志变化后的失效。原有神经排序的 101 字上下文、重开、禁学和固定首选回归保持通过。

API 28 专用 AVD 中，四个共享客户端 crate 的设备测试通过；Android 宿主通过 251 项 JVM 冒烟、JNI 语法和资源契约检查。原生 APK 已构建并安装；独立设备准备包在应用 UID 下验证夜间训练和数值缓存，核对系统 JobInfo 的充电、空闲约束。合成 SMS 经系统广播到原生键盘，空白编辑器在点击前保持空白，点击后插入代码；真实外部编辑器的普通复制事件写入共享历史，验证码消息不写入。测试授权和开关有恢复入口。

测试夹具有两个约束：以产品包启动 instrumentation 会停止输入法进程，不能同时用它验证剪贴板监听；Activity 切换时的 inputType=0 不是文本框，隐私规则会正确跳过捕获。复制事件因此改由独立编辑器在稳定文本连接后发出。一次原生长套件被重叠 instrumentation 打断，必须串行重跑，不将进程被测试停止当作产品缺陷。完整命令、字面输出、退出码、补丁重建及回滚结果保存在同一组交付角色的补充记录中。
