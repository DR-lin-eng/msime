# Agent Note: 按兴趣订阅搜狗细胞词库

Status: implemented

## Problem

已有细胞词库导入需要用户自行寻找文件，无法按兴趣发现、按编号下载或跟踪更新。初始化与后续设置需要使用同一份订阅状态。

## Decision

共享 client-services 持有订阅、官方分类页解析、限量 HTTPS 下载与日节流；host-api 通过既有词库请求提供异步任务。设置宿主可以选择兴趣分类、分页挑选具体词库或输入官方编号。下载完整且 SCEL 与词条全部校验通过后按来源编号替换命名集合；新增、删词与启停继续走集合的跨进程队列及已有词保护。默认没有订阅，不联网；输入进程只激活已准备好的队列，不请求搜狗。

## Alternatives considered

- 全站爬取并随客户端分发能离线浏览全部词库，但无必要地下载用户不需要的内容，而且引用爬虫的 MIT 许可不代表词库内容也可再分发；采用用户按需从官方站直接取得的方式。
- 各宿主自行爬取接入快，但平台之间会出现不同的大小限制、失败回退与订阅状态；因此业务放在共享 Rust 层。

## Verification

共享服务与宿主回归使用合成 SCEL 覆盖订阅持久化、更新替换、坏下载保留旧库、取消配置后的代次围栏、真实 SQLite 激活与停用。正式三态探针使用相同完整偏好输入。显式联网用例从官方分类取得 10 项、下载 363014 字节并在临时目录安装 10300 条，不把真实词库保存到源码树。共享设置类型检查、构建和初始化/词库界面测试运行；Android 原生 APK、共享 crate 设备测试与初始兴趣页也分别验证。精确命令、原始输出与未覆盖平台在任务验证记录中保留。

## Consequences

官方 HTML 可变，页面解析失败必须明确报错而非清空词库。沿用 32 个集合、每集合 50000 条的容量限制；分组跟踪最新上传的首页，展示容量与范围限制。移动系统只在设置宿主获得运行机会时检查，不承诺暂停期间下载。安装使用 `source: {type:"sogou",dictionary_id,sha256}`，编号与内容摘要和集合一起提交，避免进程中断留下第二份映射；旧版不认识该来源，降级前应先移除搜狗集合。

状态轮询只读已校验的集合元数据和待发队列，不每两秒载入全部词条；iOS 队列为空时不关闭和重建输入会话。桌面沿用现有 quiesce 租约，Android 设置宿主在下载后与待激活状态轮询时用同一维护租约有界推进，键盘活跃时保留队列，后续轮询重试；鸿蒙沿用集合同步，iOS 在键盘空闲且有完全访问时有界批量同步。

参考项目只用于核对官方入口，没有复制 Python 脚本；MIT 代码许可不适用于搜狗词库内容。下载只供用户本机使用，新来源继续参加现有第三方词条发布拦截。

API 28 大词库验收中，下载后仅由输入法生命周期补队列会在首批之后等下一次会话结束；设置宿主因此也负责在不占用输入会话时持续推进。每个状态目录只有一个激活线程，每轮有 100 毫秒软预算，最多 50 轮；锁暂忙和无进展均停止，由后续轮询继续。共享回归以 513 词和真实会话租约覆盖繁忙时队列不变、释放后全部落盘。
