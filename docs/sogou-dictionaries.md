# 搜狗兴趣词库与分组订阅

初始化最后一步可以选择兴趣分组，也可以直接跳过。以后在「设置 → 词库 → 搜狗词库与订阅」调整：

- 选择分组后下载该分组最近上传的 10 个词库；每天检查时继续发现最新的项目，已经安装的旧项目也继续更新。
- 「浏览官方分组」可以翻页查找、筛选当前页并下载单个词库。已知官网详情页的编号时，可以直接「按编号下载并跟踪更新」。
- 「自动更新已选词库」只控制之后的定时检查；关掉仍保留已经安装的内容，手动检查仍可用。未选择分组或词库时不请求搜狗。
- 每个词库可以停用、重新启用或移除。移除取消单个词库的跟踪，并记入分组排除项，之后不会被分组订阅装回来。主动按编号再次下载可以解除排除。

词库从搜狗官网直接取得，只供本机使用，不随客户端分发；其词条沿用第三方来源保护，不应发布为社区词库。实现参考 [StuPeter/Sougou_dict_spider](https://github.com/StuPeter/Sougou_dict_spider/tree/7fb80f893ee447cd90a8302a931cf06324991ec7) 的分类与下载入口，固定参考提交为 `7fb80f893ee447cd90a8302a931cf06324991ec7`，该项目代码许可为 MIT；这里没有复制爬虫脚本，也不把该许可用于词库内容。

## 下载与生效

共享 Rust 服务固定使用搜狗官方 HTTPS 主机，限制重定向、超时与响应大小。完整 SCEL 结构、读音和词条全部校验通过后才替换集合；下载失败、HTML 验证页、文件损坏或容量不足均保留旧词库。SHA-256 用于比较内容变化，不能替代第三方内容的授权或签名。

词条通过现有命名集合及个人词库队列在空闲时激活，不在按键路径联网。集合替换只移除旧版本独有、且不被其他启用集合或用户已有词条保留的词；个人学习和权重保护沿用集合机制。

默认沿用 32 个集合（包含用户和社区集合）的共享上限，每个集合最多 50000 条。最多订阅 8 个分组；超限会明确提示，不会悄悄截断安装。单个下载最多 8 MiB，转出的文本最多 16 MiB。分组是最新 10 项的动态订阅，完整分类可分页逐项选择。

自动检查只在设置宿主启动、回到前台或可运行期间进行；移动系统暂停应用时不保证后台执行。iOS 键盘须开启完全访问才能读取 App Group 的待激活队列。

## 开发验证

```sh
bash scripts/test-sogou-dictionaries-docker.sh
MSIME_SOGOU_LIVE=1 bash scripts/test-sogou-dictionaries-docker.sh
```

默认测试只用现场生成的合成 SCEL；显式的联网用例读取官方目录并在临时目录安装公开词库，不保存样本到源码树。Android 文件行为仍需按照仓库设备流程在 API 28、35 的模拟器上验证，Linux 容器测试不能替代。
